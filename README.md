# Análise de Dados de Carros (1970 - 2024)

Este repositório contém um **notebook Python** que realiza a análise de um conjunto de dados com informações sobre aproximadamente **90.000 carros** fabricados entre **1970 e 2024**. O objetivo é explorar padrões de mercado, características dos veículos e tendências ao longo do tempo.  

Esses dados permitem análises como distribuição de marcas, evolução de lançamentos, tipos de combustível e transmissão mais comuns, entre outras.

## Principais Análises

1. **Marcas com mais registros**  
   Identifica os fabricantes com maior número de carros no dataset.  

2. **Evolução de lançamentos por ano**  
   Mostra como a produção de veículos evoluiu ao longo dos anos.

3. **Combustível mais comum**  
   Analisa qual tipo de combustível é mais utilizado nos veículos.

4. **Transmissão mais utilizada**  
   Apresenta a distribuição dos tipos de transmissão mais comuns.

5. **Quantidade de tipo de transmissão por ano**  
   Mostra a evolução do uso de diferentes tipos de transmissão a partir de 2010.

## Tecnologias Utilizadas

- **Python 3**  
- **Pandas** para manipulação e análise de dados  
- **Matplotlib** para visualização de dados
